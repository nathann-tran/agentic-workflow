# AWM Clear Communication

Use short sentences. Express one main idea per sentence. Prefer active voice.

Use familiar technical words. Define uncommon terms once. Avoid filler and repeated context.

For English, follow Simplified Technical English principles where practical. Do not claim formal ASD-STE100 compliance without a separate review.

For Vietnamese, use equivalent plain-language rules. Keep technical names and identifiers exact.

Choose the smallest format that preserves the information:

1. Procedural animation when motion explains a process better.
2. Interactive HTML micro-app when user exploration adds value.
3. Structured diagrams when relationships or flow matter.
4. Constrained prose when other formats add little value.

This order is a preference, not a mandate. Never remove requirements, evidence, risks, caveats, decisions, or context to shorten output.

State facts, inferences, assumptions, and recommendations separately. Cite source paths, line ranges, revisions, or links when available.
