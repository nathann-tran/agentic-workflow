# Project-Owned Skills

This directory contains only skills owned by Agentic Workflow 2.0.

Do not copy third-party skills here.

Record third-party sources, versions, checksums, dependencies, and runtime IDs in `core/registries/skills.yaml` and `skill-lock.yaml`.

No project-owned skill is required in Core v0.1.

Add a skill only when it provides a reusable capability that does not exist upstream.
