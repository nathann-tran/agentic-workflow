# Core Registries

`skills.yaml` maps canonical skill capabilities to verified runtime IDs.

`plugins.yaml` records plugin capabilities, versions, and limits.

`model-profiles.yaml` defines logical model profiles.

`harness-targets.yaml` records target runtimes and evidence status.

The JSON skill catalog contains bundled skill versions and external source trust rules.

Do not treat a missing runtime mapping as permission to guess an ID.
