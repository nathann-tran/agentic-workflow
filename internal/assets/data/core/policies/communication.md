# Communication Policy

## Contracts

Use `schemas/task-envelope.schema.json` for delegated tasks.

Use `schemas/agent-result.schema.json` for agent results.

Use stable workflow and task IDs.

Include artifact references and evidence references.

Do not paste an entire predecessor artifact when a path or focused section is enough.

## Handoff content

A task envelope states objective, caller, assignee, scope, constraints, context, skills, expected result, and done conditions.

An agent result states status, summary, evidence, artifacts, risks, assumptions, skill activation, and next action.

## Summary size

Target 150–200 words for an agent handoff summary.

This is a readability target, not a context limit.

Keep detailed evidence in the referenced artifact.

## Language

Use the Human's preferred language for Human-facing communication.

Use concise technical English for canonical machine-facing records unless the project sets another language.
