# Oh My Pi adapter

AWM writes global Markdown agents under `~/.omp/agent/agents/`.
It adds a managed block to `~/.omp/agent/AGENTS.md`.

OMP supports native agent tool lists and spawn allowlists.
Worker receives only read-oriented tools.
Builder tool lists do not enforce exact per-file write paths.
Use an isolated worktree and Human-approved commands.
Configure delegation depth in the OMP runtime.
